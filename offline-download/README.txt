Eaglercraft Ranked Beta 1.0 offline page

The HTML file is a direct copy of:
https://play.eaglercraftranked.com/client/current/

The downloaded page contains its client payload inline, so there are no
separate site assets in this package. Open eaglercraft-ranked.html in a
modern browser. If direct file opening is unsupported, serve this folder
from a local static HTTP server and open the resulting local URL.

This package preserves the page and client payload; it does not make ranked,
multiplayer, authentication, or other server-dependent features available
without network access.
